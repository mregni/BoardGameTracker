---
title: Logging
description: Configure log levels and view logs for BoardGameTracker.
---

BoardGameTracker logs with Serilog. To change the log level, set the `LOGLEVEL` environment variable and restart the container. The available levels are `debug`, `info`, `warn` and `error`; the default is `warn`.

## Viewing logs

Follow the container output with:

```sh title="Terminal"
docker compose logs -f boardgametracker
```

The same logs are written to `./logs/app-<date>.log` in the mounted `logs` folder, one file per day; the last 30 files are kept.

## Sentry integration

Set `STATISTICS_ENABLED=true` to send error reports to Sentry. It is off by default. When it is on:

- the server sends unhandled exceptions and a 10% sample of performance traces;
- the browser sends errors, a 20% sample of performance traces and scrubbed session replays (10% of sessions, and every session with an error).

No IP address or server name is sent, and reports are scrubbed before they leave. The reports go to the maintainer's Sentry project and help fix errors. `SENTRY_DSN` redirects the server reports to your own project; browser reports always use the project built into the image.
